## What to build

Add a test for rule **MA0231** — *An EventSource event method must not be static* — from the
`Meziantou.Analyzer` analyzer.

`EventSource` discovers event methods reflectively over the *instance* methods of the concrete
type. A `static` method carrying `[Event]` is never picked up, so the event silently never appears
in the manifest.

This rule is configured as **`warning`** in
`packages/Opinionated.DotNet.CodingStandards/pkgsrc/config/analyzers/Analyzer.Meziantou.Analyzer.editorconfig`,
so it surfaces as a SARIF **error** — assert with `HasError`.

## How to implement the test

Add a `[Fact]` to `MeziantouAnalyzersEventSourceShould.cs` (created by issue 001):

```csharp
[Fact]
[RuleDoc("MA0231", "An EventSource event method must not be static",
    HelpLink = "https://github.com/meziantou/Meziantou.Analyzer/blob/main/docs/Rules/MA0231.md")]
public async Task ProhibitStaticEventSourceEventMethod()
{
    using var project = await CreateProjectBuilderAsync();
    await project.AddFileAsync("Program.cs", """
        using System.Diagnostics.Tracing;
        namespace test;
        public sealed class MyEventSource : EventSource
        {
            [Event(1)]
            public static void Started(string message)
            {
            }
        }
        public static class Program { public static int Main() => 0; }
        """);
    var buildOutput = await project.BuildAndGetOutputAsync();

    buildOutput.HasError("MA0231").ShouldBeTrue();
}
```

### Watch out for

- **Keep the class `sealed`** — otherwise `MA0226` fires as well.
- **The body must be empty.** `WriteEvent` is a protected *instance* method, so a `static` event
  method cannot call it — the code would not compile. An empty body is the only shape that both
  compiles and is static.
- The empty body may draw unrelated diagnostics (for example Sonar's "methods should not be
  empty"). That is harmless: the assertion is specifically `HasError("MA0231")`, and other
  diagnostics in the same SARIF file do not affect it. Only investigate if `MA0231` itself is
  missing.
