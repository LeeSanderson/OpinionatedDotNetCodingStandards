## What to build

Add a test for rule **MA0239** — *Use 'typeof' instead of 'GetType()' when the type is sealed* —
from the `Meziantou.Analyzer` analyzer.

When an expression's static type is `sealed`, its runtime type can only ever be that same type, so
`expr.GetType()` is a virtual call that can only return `typeof(ThatType)`. Replacing it with
`typeof(...)` is exactly equivalent, resolved at compile time, and cannot throw on a null receiver.

This rule is configured as **`warning`** in
`packages/Opinionated.DotNet.CodingStandards/pkgsrc/config/analyzers/Analyzer.Meziantou.Analyzer.editorconfig`,
so it surfaces as a SARIF **error** — assert with `HasError`. Note that **upstream ships this rule
at `suggestion`**; this package deliberately enforces it at `warning` (see the PRD's Implementation
Decisions), so do not "fix" the assertion to `HasNote` — if it reports as a note, something is
wrong with the editorconfig, not with the test.

## How to implement the test

Add a `[Fact]` to `MeziantouAnalyzersCoreShould.cs` (currently ~441 lines — well under the
1000-line split threshold, so add it to the end of the existing class; issue 002 adds `MA0227` to
the same file):

```csharp
[Fact]
[RuleDoc("MA0239", "Use 'typeof' instead of 'GetType()' when the type is sealed",
    HelpLink = "https://github.com/meziantou/Meziantou.Analyzer/blob/main/docs/Rules/MA0239.md")]
public async Task UseTypeofInsteadOfGetTypeOnSealedType()
{
    using var project = await CreateProjectBuilderAsync();
    await project.AddFileAsync("Program.cs", """
        using System;
        namespace test;
        public sealed class Sealed
        {
        }
        public class C
        {
            public Type M(Sealed value) => value.GetType();
        }
        public static class Program { public static int Main() => 0; }
        """);
    var buildOutput = await project.BuildAndGetOutputAsync();

    buildOutput.HasError("MA0239").ShouldBeTrue();
}
```

### Watch out for

- **The receiver's static type must be `sealed`.** `value.GetType()` where `value` is typed as a
  non-sealed class does not fire — that call genuinely can return a derived type.
- A `string` receiver is a good BCL alternative if the local `sealed` class does not fire
  (`System.String` is sealed): `public Type M(string value) => value.GetType();`.
- `using System;` is needed for the `Type` return type.
- Do not use `this.GetType()` inside the sealed type as the first attempt — the analyzer may treat
  `this` differently from an ordinary expression. Keep it as a fallback shape if the parameter form
  does not fire.
