## Shipped severity — read this before writing the assertion

MA0217 ships at **`suggestion`**, not `warning`. Assert with
`buildOutput.HasNote("MA0217").ShouldBeTrue()` — `HasError` will **not** match.

MA0217 is deliberately kept at `suggestion` because it fires on every non-capturing lambda,
including idiomatic LINQ (32 sites in this repo alone); see the rationale in `issues/prd.md`.

## How to implement the test

This rule fires very readily — any lambda that captures no state. A plain LINQ projection is
enough:

```csharp
[Fact]
[RuleDoc("MA0217", "Use a static lambda",
    HelpLink = "https://github.com/meziantou/Meziantou.Analyzer/blob/main/docs/Rules/MA0217.md")]
public async Task UseStaticLambda()
{
    using var project = await CreateProjectBuilderAsync();
    await project.AddFileAsync("Program.cs", """
        namespace test;
        using System.Collections.Generic;
        using System.Linq;

        public static class Program
        {
            public static int Main()
            {
                var values = new List<string> { "a", "bb" };
                // Non-capturing lambda — should be 'static x => x.Length'.
                return values.Select(x => x.Length).Sum();
            }
        }
        """);
    var buildOutput = await project.BuildAndGetOutputAsync();
    buildOutput.HasNote("MA0217").ShouldBeTrue();
}
```

Note that other rules may also fire on this source; that is fine, the assertion only checks
MA0217. If unrelated rules turn the build red in a way that blocks the SARIF output, add the
noisy IDs to `NoWarn` via `properties:` rather than restructuring the trigger.

## Confounder playbook (exhaust before marking untestable)

1. **Add a package reference** if the rule guards on types in an external package.
2. **Use stub types** if the rule merely requires a type to exist in the compilation.
3. **Pin `LangVersion=12`** if C# 13 overload routing might redirect the call.
4. **Set `ignore_internalsvisibleto=true`** if the rule is friend-assembly-sensitive.
5. **Check `EnforceOnBuild`** — `EnforceOnBuild.Never` rules are silent at `dotnet build`.
6. **Check the reporting analyzer's assembly path** — `src/Features/` means IDE/LSP-only.
7. **Check the mscorlib gate** — not applicable to `net10.0` targets.

Only move the rule to `UntestableRules.cs` after exhausting all of the above.
